Agentforce

I design AI agents on Salesforce Agentforce that automate business processes and support customers, using your own Salesforce data and workflows.

An agent I build is made of four parts, and I treat access and security as part of each one.

Topics and subagents

What the agent is responsible for, and how it hands work between areas.

Instructions

How the agent should behave and respond in each topic.

Actions

What it can do, including custom Apex-based actions for business logic.

Data and access

Which Salesforce records it can use, and who it can show them to.
